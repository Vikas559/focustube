# FocusTube Web App

A mobile-first YouTube queue player with Apple-style glass UI, queue ordering, playlists and sleep timer.

## Deploy
Upload the contents of this folder to any HTTPS static host:
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

Do not open `index.html` through Android's `content://` file viewer. A normal HTTPS origin is required for reliable YouTube embedding.

This app streams through YouTube's official embedded player. It does not download or convert YouTube videos to audio.
